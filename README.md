# Виселица (Hangman)

Консольная игра "Виселица" на Java — Проект 1 роадмапа [Java Backend Learning Course](https://zhukovsd.github.io/java-backend-learning-course/) Сергея Жукова.

ТЗ: https://zhukovsd.github.io/java-backend-learning-course/projects/hangman/

## Как играть

1. Клонировать репозиторий
2. Открыть проект в IntelliJ IDEA (Maven-проект)
3. Запустить `Main.java`
4. В меню выбрать "1" — новая игра
5. Вводить по одной букве, пытаясь угадать слово, пока не закончатся попытки (6 ошибок) или слово не будет отгадано полностью

## Технологии

- Java 21
- Maven

## Архитектура

Проект разбит на 4 класса, каждый со своей зоной ответственности:
- `WordDictionary` — чтение словаря слов, выдача случайного слова
- `GameSession` — состояние одного раунда игры (загаданное слово, введённые буквы, счётчик ошибок)
- `HangmanArt` — ASCII-отрисовка виселицы по числу ошибок
- `Main` — точка входа, меню, игровой цикл
