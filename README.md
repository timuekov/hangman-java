# Виселица (Hangman)

Консольная игра «Виселица» на Java — Проект 1 роадмапа [Java Backend Learning Course](https://zhukovsd.github.io/java-backend-learning-course/) Сергея Жукова.

ТЗ: https://zhukovsd.github.io/java-backend-learning-course/projects/hangman/

## Как играть

1. Клонировать репозиторий.
2. Открыть проект в IntelliJ IDEA (Maven-проект).
3. Запустить `Main.java`.
4. В меню выбрать `1` — новая игра.
5. Вводить по одной букве русского алфавита, пытаясь угадать слово.
6. Игра продолжается до полного угадывания слова или достижения 6 ошибок.

## Технологии

- Java 21
- Maven

## Архитектура

Проект разбит на 6 основных классов:

- `WordDictionary` — загрузка словаря и получение случайного слова.
- `SecretWord` — хранение загаданного слова, учёт правильно угаданных букв, формирование скрытого представления слова и проверка победы.
- `GameSession` — управление состоянием игрового раунда, регистрация попыток, учёт ошибок и проверка завершения игры.
- `HangmanArt` — хранение и получение ASCII-изображений виселицы.
- `GameController` — взаимодействие с пользователем и управление игровым процессом.
- `Main` — конфигурация зависимостей и запуск приложения.

## Code review

После первоначальной реализации проект прошёл внешнее code review.

По результатам ревью были исправлены:

- обработка некорректного ввода в меню;
- проверка ввода букв русского алфавита;
- обработка одной и той же буквы в разных регистрах;
- отображение уже введённых букв;
- отображение финальной стадии виселицы при поражении;
- обработка ошибок при загрузке словаря;
- магические значения и дублирование констант;
- форматирование строк;
- конфигурация `WordDictionary` через конструктор;
- разделение проверки и изменения состояния в `GameSession`;
- ответственность `Main`: управление игрой вынесено в `GameController`;
- выделение класса `SecretWord`, отвечающего за загаданное слово и связанную с ним логику.
